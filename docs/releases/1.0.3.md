# xszs 1.0.3

## 自 1.0.2 以来的更新

- 补齐每个文件最多 16 个不同标签的服务端限制，覆盖单项追加与标签成员集合的批量替换。
- 重复关联和批量中的重复资产 ID 不重复计数。超限返回 HTTP 400 `bad_request`，批量请求整体回滚，不保留部分新增或移除。
- 标签计数与关联写入在同一 SQLite 写事务内完成，避免并发请求争用最后一个名额时越界或发生事务升级错误。
- 历史超限关联不自动清理，继续允许读取、保留和删除；新增关联仍受上限约束。
- 软件、管理 Web 与发行目录更新为 1.0.3。协议维持 1.0.0，数据库与配置身份不变，不迁移或删除已有数据；共享依赖保持本地已验证的 xcss 1.0.7 精确修订。

## 验证与接口说明

新增临时 SQLite/HTTP 回归覆盖 16/17 标签边界、重复追加、批量替换、失败原子性、历史超限与并发追加。
错误字段、幂等和批量语义见[图库 API](../gallery-api.md)。
